# DS-HW 作業

這個 repository 保留五份作業，分別以獨立網頁呈現：

- [二元搜尋樹互動視覺化](index.html)：BST 插入、搜尋、刪除、走訪與操作步驟播放。
- [海大餐廳排隊系統](haida-restaurant-queue.html)：候位登記、排隊名單與下一位叫號。
- [最大堆積樹互動視覺化](max-heap.html)：輸入整數、插入與上浮、取出最大值及下沉操作。
- [雜湊表鏈結法](hash-table.html)：手動輸入 15 個整數，以除以 13 的餘數建立鏈結雜湊表。
- [圖形走訪](graph-traversal.html)：使用給定的 6 個頂點和 9 條無向邊，逐步演示 BFS 與 DFS。

各頁面也可以透過頂部連結互相切換。
